# My Astro Blog

A small Astro-powered personal blog with Markdown and MDX posts, RSS, sitemap support, and custom styling.

## Features

- Astro-based static blog
- Markdown and MDX content support
- RSS feed and sitemap integration
- Custom page layouts and reusable components
- Local font configuration

## Setup

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Project Structure

- Content lives in `src/content/blog/`
- Site configuration is in `astro.config.mjs`
- Node.js version: `>=22.12.0`

## Notes

The `site` value in `astro.config.mjs` should be updated before deployment to your live domain.
